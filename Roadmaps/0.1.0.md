# Rooftop Runner 0.1.0 路线图

状态：`发布准备中`

目标：交付可验证的三关跑酷版本，完成 Android Release 正式签名与 TapTap 首次上架准备；日常开发只构建 Mac Debug，正式打包时才构建 Android Release APK。

## 当前基线

- 产品版本：`0.1.0`
- Unity：`2022.3.62f1c1`
- Android：IL2CPP ARM64、最低 API 24、目标 API 35、正式 v2 签名
- Mac：Debug Universal Binary，用于本地测试
- 玩法：三关、三条命、检查点恢复、逐关提速、终点线和减速庆祝
- 自动化：PlayMode `26/26` 最近一次完整验证通过
- 公开隐私政策：`https://hackcpp.github.io/Runner/privacy/`

历史实现与完整验收证据见 [Archive/0.1.0-pre-release-history.md](Archive/0.1.0-pre-release-history.md)。只有需要追溯既有决策或 SHA 时才读取该文件。

## 当前迭代

### TapTap 首次上架准备

状态：`进行中`

已完成：

- [x] Android Release 使用项目独立证书，构建缺少凭据时不会回退到 Debug 签名。
- [x] Android 应用显示名为 `天台疾跑`，包名保持 `com.hackcpp.rooftoprunner`。
- [x] 构建图标与 TapTap 上传图标使用同一画稿。
- [x] 三关流程、生命 HUD、检查点恢复、终点线和通关庆祝已实现并通过人工验收。
- [x] 隐私政策按 TapTap 模板结合 APK 实际能力扩充并通过 GitHub Pages 发布。
- [x] `Distribution/` 与 Git 仓库隔离，商店上传材料只保存在本地发布工作区。

待完成：

- [ ] 重录三关版本的 3 张 `1920x1080` 截图和连续实机视频，覆盖生命 HUD、检查点恢复与通关庆祝。
- [ ] 重新设计宣传图，统一屋顶透视和人物比例，不使用拉伸或与实机不符的画面。
- [ ] 在 Android ARM64 真机对照最终截图、手势引导、安全区域、音频、发热和帧率。
- [ ] 正式提交前复核 TapTap 名称占用、页面字段、APK 包信息和签名。
- [ ] 由发布主体补齐 TapTap 要求的资质、ISBN 和未成年人防沉迷材料。
- [ ] 对 release keystore 与 Keychain 凭据完成安全的离机备份。

完成标准：

- TapTap 必填文案、图标、截图、视频、宣传图、隐私政策和 APK 均可直接提交，规格与实际游戏一致。
- APK 应用名、包名、版本、架构、SDK 级别和 v2 签名全部复核通过。
- 最终 Android Release 在至少一台 ARM64 真机完成完整流程烟测。
- 外部资质和防沉迷材料状态明确；未满足的平台硬性要求不得标记为已发布。
- 发布提交或 tag、APK SHA-256、测试结果和人工验收记录写入本文件。

## 已接受风险

### CVE-2025-59489

状态：`暂缓`

用户于 2026-07-31 明确要求当前阶段先忽略该高危漏洞，因此 `0.1.0` 暂不执行 Unity `2022.3.67f2` 安全升级。该决定只记录风险，不表示漏洞已修复；后续恢复处理时必须重新运行完整 PlayMode、Android Release 构建、APK 签名和真机回归。
